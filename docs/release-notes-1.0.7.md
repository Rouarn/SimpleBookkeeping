## 一、应用内更新弹窗（updateLog，纯文本）

小绿记账 1.0.7

全新液态玻璃界面

· 底部导航改为悬浮玻璃条，中间记账按钮重做：纸白圆钮 + 四色细环

体验修复
· 修复分类图标横向滚动后消失、划回开头也不显示的问题

· 修复「截止本单该月目前支出」金额偏大：同一分钟记的多笔会被重复累计
· 流水页支出 / 收入图标改为更直观的 ↑ / ↓
· 保存、登录、更新等主按钮统一为同一套纸白材质

性能
· 预加载记账页，点「+」打开更快
· 优化壁纸与玻璃的绘制开销，滑动更跟手

## 三、社群 / 公众号公告（长版）

**小绿记账 1.0.7 发布：整站换上液态玻璃**

这一版把界面整体重做了一遍。

**玻璃，而不是白卡片**
每个卡片、导航条、弹窗都变成半透明玻璃：背后的壁纸颜色会透上来，
滑动时内容从玻璃下方穿过。浅色是近白的纸面，深色是近黑的墨底，
两套都重新调过对比度。

**底部导航**
改成了悬浮玻璃条，中间那颗记账按钮重新设计：纸白圆钮，
外面一圈四色细环（橙 / 蓝 / 紫 / 黄），点下去有轻微下沉。

**顺手修掉的问题**
· 分类图标横向滑动后消失、划回开头也不显示
· 内容不满一屏时仍然能滚动，底部还露着滚动条
· 「截止本单该月目前支出」金额偏大——同一分钟连续记的多笔被重复累计
· 流水页的支出 / 收入图标换成更直观的 ↑ / ↓

**快了一点**
记账页做了预加载，点「+」基本即时打开；壁纸与玻璃的绘制开销也降了一档。

**新的门面**
应用图标、启动图、默认头像统一换成四芒星标记。
